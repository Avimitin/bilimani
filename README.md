# chart-requester：IIDX 弹幕点歌

让观众在哔哩哔哩直播间发送 `点歌 曲名`，主播的游戏就会在选曲界面自动定位到对应歌曲。多首点歌按顺序排队；由主播决定是否开始游玩。

## 第一次安装

### 1. 下载并解压

1. 打开 [下载页面](https://github.com/Avimitin/chart-requester/releases)。
2. 展开对应版本的 **Assets**，下载 `chart-requester-版本号.zip`，例如 `chart-requester-0.1.1.zip`。`Source code` 是源代码，安装时不需要下载。
3. 将 ZIP 解压到本机一个可以保存文件的文件夹。

解压后应能找到 `chart_requester.dll` 和 `chart-requester.example.toml`。DLL 由启动器加载，不需要双击打开。

### 2. 准备主播身份码

1. 用主播账号登录 [哔哩哔哩身份码页面](https://play-live.bilibili.com/)，复制自己的身份码。找不到入口时，可参考 [blivechat 的获取说明](https://blive.chat/help)。
2. 稍后在游戏内控制台粘贴身份码。默认连接方式不需要填写直播间号。

无需创建或编辑配置文件，插件会自动保存设置。身份码不要展示在直播画面或发到弹幕里。

### 3. 让启动器加载插件

确定游戏还没有启动，把 DLL 放进游戏根目录的 modules 目录下，然后在 bat 或者 spicecfg 里引入这个 DLL 文件。请使用支持 SDK v0.4 D3D9 绘制回调的 Spice2x，以便打开配置界面。

```bat
spice64.exe -k chart_requester.dll
```

- **用 `.bat` 文件启动：** 右键该文件，选择编辑，找到运行 `spice64.exe` 的那一行，在该行末尾加一个空格，再加上面的参数。
- **用 spicecfg 启动：** 启动 spicecfg, 选择 options 选项卡，在 inject dll hook 选项填入 `chart_requester.dll`。

如果解压到了其他位置，把路径改成你自己的 DLL 完整路径。无需替换游戏的 `bm2dx.dll`。

### 4. 在控制台设置直播连接

1. 按平时的流程开启直播，并用刚修改的启动方式打开游戏。
2. 进入单人 SP 普通选曲界面，双击另一侧的 Start：1P 登录就双击 2P Start，反之亦然。
3. 在控制台选择「直播连接」，粘贴身份码，点击 **「应用并保存」**。
4. 确认顶部显示 **「弹幕已连接」**，即可关闭控制台开始点歌。无需重启游戏。

看到 **「弹幕已连接」** 表示连接成功。插件运行后会自动生成以下文件：

| 文件 | 用途 |
| --- | --- |
| `chart-requester.toml` | GUI 设置的持久化存储，自动创建和更新 |
| `obs/queue.txt` | 当前点歌和等待队列 |
| `obs/interaction.txt` | 候选歌曲、选择提示、连接状态和错误提示 |
| `chart-requester.log` | 出问题时用于排查的日志 |

如果文件没有生成，或出现错误，先看下方的 [常见问题](#常见问题)。

### 5. 在 OBS 中显示点歌信息

游戏启动后，用浏览器打开 **<http://127.0.0.1:32133/queue>**，即可查看实际点歌状态。

1. 在 OBS 当前场景的「来源」中点击 **＋**，添加「浏览器」，命名为「点歌队列」。
2. 不勾选「本地文件」，在 URL 中填写 `http://127.0.0.1:32133/queue`，宽度设为 **480**、高度设为 **800**。
3. 将来源摆放到直播画面的合适位置，并为底部弹出提示预留空间。没有提示时，这部分完全透明。

当前仅支持 OBS 和游戏运行在同一台电脑。

如果喜欢纯文字方式，可添加两个「文本（GDI+）」来源，勾选「从文件读取」，分别选择 **DLL 所在文件夹**下的 `obs/queue.txt` 和 `obs/interaction.txt`，再自行设置字体与颜色。

### 6. 发一条弹幕试试

在自己的直播间发送：

```text
点歌 AA
```

如果出现多首候选，由发送这条弹幕的同一个账号再发送一个编号，例如 `1`。队列空闲且游戏处于可操作的选曲界面时，游戏会定位到选中的歌曲；有其他点歌时则加入等待队列。

能看到提示、选出歌曲并完成定位，就可以开始使用了。

## 观众怎么点歌

发送 `点歌`、一个空格，再加曲名：

```text
点歌 冥
点歌 AA SPA
点歌 AA -rebuild- DPA
```

难度可以不填，不填时使用主播当前的 SP/DP 模式，并沿用游戏当前难度选择。指定难度时，使用下表中的写法，大小写均可：

| 难度 | SP | DP |
| --- | --- | --- |
| Beginner | SPB | DPB |
| Normal | SPN | DPN |
| Hyper | SPH | DPH |
| Another | SPA | DPA |
| Leggendaria | SPL | DPL |

主播正在 SP 模式时点 DP 的歌会被直接跳过，反之亦然。不存在、未解锁或当前模式不可用的谱面会提示失败。

曲名支持模糊匹配，可以省略部分字符，但保留的字符顺序要一致。遇到多首候选时，提示会显示编号，例如：

```text
1. AA
2. AA -rebuild-
```

**由点歌的同一个账号，在默认 60 秒内只发送编号**，例如 `2`。其他人的回复不会替你选择。即使输入了完整曲名，只要还有其他候选，也需要选择。

超时后重新发送点歌命令即可。等待选择时再次点歌，会替换自己上一次尚未确认的选择。

## 主播日常使用

每次开播时，启动游戏、进入普通选曲界面，确认「弹幕已连接」，并确认 OBS 点歌面板能正常显示。

- **点歌按先后排队。** 默认最多等待 20 首，队列满时新请求会收到提示。
- **定位成功就离开等待队列。** 该歌曲会显示为「当前点歌」，不会自动开始游玩。
- **不想打这首，可以直接选别的歌。** 开始游玩任意歌曲后，当前点歌就算结束；回到选曲界面时再处理下一首。
- **一直没开始游玩，默认 10 分钟后跳过。** 如果此时还在选曲界面，会继续处理下一首；游玩途中不会跳歌。
- **双击另一侧 Start 打开控制台。** 单人 SP 选曲时，1P 游玩就双击 2P Start，2P 游玩就双击 1P Start。两次按下默认间隔不超过 400 毫秒，中间需松开。再次双击或按 Esc 关闭；队列为空也能打开。
- **想立即跳过或删除点歌，使用「弹幕与队列」页。** 左侧查看实时弹幕，右侧点击「跳过当前点歌」或等待项旁的「删除」。控制台打开期间暂停自动定位，关闭后继续处理队列。
- **所有人都可以点歌。** 队列和待选候选在游戏重启后清空。

控制台需要支持 **SDK v0.4 D3D9 绘制回调**的 Spice2x。双击开关仅在普通选曲、单人 SP 时生效，DP、双人游玩、游玩途中和游戏菜单弹窗内不生效。进入游玩后控制台自动关闭。对侧 Start 仍然只读取、不拦截。

窗口打开后，使用**当前登录侧**的手台操作（1P 登录用 1P，2P 登录用 2P）：

| 操作 | 按键 |
| --- | --- |
| 下一项 / 上一项 | B1 / B2，支持长按重复 |
| 确认、切换选项、点击按钮 | B6 |
| 返回分类；在分类上再次按下则关闭 | B7 |
| 左右移动；聚焦数值时减小 / 增大 | 转盘左右转动 |

可以用手台切换页面、跳过 / 删除点歌、调整数值与开关，并选择「应用并保存」。别名、身份码等自由文字仍使用键盘或粘贴输入，鼠标也可照常操作。窗口打开时，当前侧七个琴键与转盘暂时用于控制台；关闭后恢复，已按住的琴键需先松开，避免误操作游戏。

控制台包含以下页面：

| 页面 | 可以做什么 |
| --- | --- |
| 弹幕与队列 | 查看最近 500 条弹幕及处理日志、删除等待项、跳过当前点歌；日志显示入队、等待观众选择、拒绝原因或忽略原因，取消「跟随最新」可翻阅历史 |
| 歌曲别名 | 两列编辑别名与完整曲名 / 歌曲 ID；上方搜索框实时模糊筛选，支持新增、删除 |
| 点歌规则 | 调整容量、候选数量、超时与冷却 |
| 直播连接 | 修改身份码或直播间设置，应用后自动重连 |
| OBS 显示 | 修改浏览器来源端口、文本路径与提示时间 |
| 按键操作 / 日志 | 调整双击间隔和日志选项 |
| 游戏适配 | 查看启动时绑定的模块和曲库设置 |

修改设置后点击 **「应用并保存」**。未保存的修改可以撤销；关闭窗口不会自动保存。身份码等凭据隐藏显示。弹幕查看不受日志的 `danmu` 开关影响。

## 常用设置

在游戏内控制台选择相应页面，修改后点击「应用并保存」即可生效。设置会自动写入 DLL 旁的 `chart-requester.toml`，下次启动自动恢复。这个文件用于持久化存储，日常使用无需手动编辑。

热更新不会清空队列、候选或已有倒计时；新规则用于后续请求。配置无效、别名无法确定歌曲或新端口被占用时，本次修改不会应用。若提示配置文件被其他程序修改，先重新载入再编辑。

以下设置都在「点歌规则」页，时间单位为秒：

| 想调整什么 | 设置名称 | 默认值 | 例子 |
| --- | --- | --- | --- |
| 等待队列最多多少首 | 队列容量 | `20` | 改为 `10`，最多等待 10 首 |
| 一次最多显示几个候选 | 候选歌曲数 | `5` | 改为 `3`，最多显示 3 个 |
| 等观众回复编号多久 | 候选选择超时 | `60` | 直播延迟较高时改为 `120` |
| 当前点歌多久没人打就跳过 | 当前点歌超时 | `600` | 改为 `300`，等待 5 分钟 |
| 同一观众多久能成功点一次 | 每人点歌冷却 | `0` | `0` 不限制，`300` 为每 5 分钟一次 |

想让观众用昵称点歌，在「歌曲别名」页点击「添加别名」，例如：

| 别名 | 曲名 / ID |
| --- | --- |
| 红武士 | SAMURAI-Scramble |
| 性感迪斯科 | Sense 2007 |

应用后，观众就可以发送 `点歌 红武士`。

右边填写游戏里的完整曲名；遇到同名歌曲时，也可以直接填写歌曲 ID。别名配置有问题时，界面会提示错误。

双击速度可在「按键操作」页调整，默认 400 毫秒，可设置 100–2000 毫秒。

想把 OBS 文件放到其他位置，在「OBS 显示」页修改「队列文本文件」和「交互文本文件」，然后在 OBS 中重新选择文件。

网页界面默认开启。如需关闭或更换端口，在「OBS 显示」页调整「启用浏览器来源」或「本机端口」。应用端口修改后，将 OBS URL 中的 `32133` 改成相同数字。关闭浏览器来源后，原来的文本文件仍可使用。

要调整网页样式，可在 OBS 浏览器来源的「自定义 CSS」末尾添加，例如：

```css
:root {
  --accent: #dfbf83;             /* 点缀颜色 */
  --title-size: 26px;            /* 当前曲名字号 */
  --panel: rgba(18, 22, 25, .94); /* 面板颜色与不透明度 */
  --radius: 9px;                 /* 圆角大小 */
}
```

这里修改后点击 OBS 的「确定」即可，不需要重启游戏。字号增大或曲名较长时，可相应增加浏览器来源高度，避免内容被裁掉。

## 常见问题

### 双击另一侧 Start 没反应？

先确认是在单人 SP 的普通选曲界面。按的是另一侧 Start，中间要松开；如果按得较慢，可增大 `controls.double_tap_ms`。还需在 Spice2x 中正确绑定两侧 Start。队列为空不影响打开窗口。

查看日志中的 `[input]`：`active_side=Some(1)` / `Some(2)` 表示可用的游玩侧；`sdk_status=-1` 表示未获得 SDK 按键接口，`-2` 表示尚未读取，`0` 表示读取成功。再看 `[gui]`：`status=-1` 表示缺少绘制接口，请升级到支持 SDK v0.4 D3D9 回调的 Spice2x；`0` 表示已注册，`1` 表示正在绘制。旧版启动器仍可点歌，但无法显示控制台。新绘制接口只支持 D3D9 游戏画面。

### 只填身份码，插件怎么知道我的直播间？

身份码用于授权连接主播的直播间。默认方式会通过 blivechat 的公共服务创建连接，再接收哔哩哔哩弹幕，服务返回的信息包含对应直播间。因此只需要填写身份码，`room_id` 保持默认即可。无需安装或运行 blivechat。

### 提示「弹幕断开」「认证失败」或「身份码无效」怎么办？

先查看 `obs/interaction.txt` 中的具体原因，再依次检查：

1. 已在「直播连接」页启用弹幕连接，并点击「应用并保存」。
2. 填入的是主播身份码，复制时没有多余空格；使用刷新后的身份码时，也更新了配置。
3. 网络能正常访问哔哩哔哩和 blivechat 公共服务。短暂断线时插件会自动重连。
4. 如果提示连接数量达到上限，关闭不再使用的重复弹幕连接，等待一段时间后再试。

仍然失败时，请按下方说明提供日志。

### 显示「等待游戏曲库」怎么办？

先进入普通 STANDARD / FREE / PREMIUM FREE 选曲界面，再重新发送点歌。首次进入选曲前，插件还没有获得点歌所需的信息。

如果已经在这个界面仍持续提示等待，请确认使用的是最新版插件，然后退出并重新启动游戏。仍未恢复时，请附上日志反馈。

### 网页打不开，或者 OBS 浏览器来源没有内容？

先启动游戏，再用普通浏览器打开 `http://127.0.0.1:32133/`。网页服务随插件启动，关闭游戏后也会停止。

- 普通浏览器能打开：核对 OBS URL 和端口，不要勾选「本地文件」，并点击来源属性中的「刷新当前页面缓存」。如果 OBS 早于游戏启动，也可以这样刷新。
- 普通浏览器打不开：检查 DLL 是否已加载、「OBS 显示」页是否启用了浏览器来源，以及日志中是否有「网页界面启动失败」。
- 提示端口被占用：在「OBS 显示」页把本机端口改为其他端口，例如 `32134`，应用后同时更新 OBS 地址。网页启动失败不会阻止原有文本点歌。

### OBS 文本来源没有文字，或者文字不更新？

先用记事本打开 OBS 正在读取的那份 `.txt` 文件：

- 文件内容正常：检查 OBS 是否勾选「从文件读取」、路径是否正确，以及来源是否可见。
- 文件不存在：检查插件是否加载成功、DLL 路径是否正确、插件文件夹能否保存文件。
- 文件里有错误提示：按该提示排查。不要选择 `.toml` 配置文件或 `.log` 日志作为 OBS 来源。

### 发了弹幕，没有跳到歌曲？

查看「点歌提示」和「点歌队列」。可能正在等待你回复候选编号，也可能排在其他点歌之后。点歌命令中的 `点歌` 后面需要有空格。

游戏需要处于可操作的普通选曲界面；菜单、过场和游玩途中不会跳歌。相反模式、未解锁或不可用的谱面也无法定位。

### 搜不到昵称，或者拼错字也搜不到？

模糊搜索允许省略字符，不会自动纠正所有错别字。先试试完整曲名；常用中文昵称可以在「歌曲别名」页添加。

### 提示「Unsupported bm2dx.dll build」或版本不兼容？

当前只适配了上方列出的 IIDX 33 游戏版本。同为 IIDX 33，不同更新包也可能不兼容。仅修改版本号文字不能解决；请等待相应适配，或在反馈中注明自己的游戏版本和报错。

### 改了配置却没生效，或提示配置错误？

修改后需要点击「应用并保存」，仅关闭窗口不会保存。若界面提示未应用，请按具体原因修正，例如重复别名、无效曲名或端口被占用。保存失败时原设置继续生效。

如果提示文件被其他程序修改，可点击「重新载入文件」恢复磁盘上保存的设置，再继续编辑。

### 怎么更新、关闭或移除插件？

更新前先退出游戏，备份自己的 `chart-requester.toml`。解压新版本并替换 DLL，保留该文件即可恢复已保存的设置；新增选项会使用默认值，并显示在控制台中。

暂时停止接收点歌，可在「直播连接」页取消启用并应用。完全移除时，退出游戏，删除启动命令中对应的 `-k "…\chart_requester.dll"` 参数，再删除插件文件夹即可。

### 遇到问题，应该提供什么？

在 [问题反馈页面](https://github.com/Avimitin/chart-requester/issues) 说明插件版本、游戏版本、当时所在界面、发送的点歌命令，以及实际看到的提示。附上 DLL 旁 `chart-requester.log` 中出问题时间附近的内容；较早的日志可能在 `.log.1` 等文件中。

日志默认记录收到的弹幕及处理结果。分享前检查其中的用户名、弹幕等个人信息，**不要上传自己的 `chart-requester.toml` 或身份码**。想减少日常日志，可在「日志」页改为普通级别并应用；排错时改回详细级别。
