# 设置与使用帮助

首次安装见 [README](../README.md)。发布包已带默认配置，只有需要调整时才编辑这些文件。

## 修改监听地址

用文本编辑器打开 DLL 旁的 `bilimani_iidx.json`，找到：

```json
"listen": "127.0.0.1:32133"
```

例如把端口改成 `32135`，保存后重启游戏，并把 OBS 地址里的 `32133` 同样改为 `32135`。

OBS 在另一台电脑时，把这里的 `127.0.0.1` 改为游戏电脑的局域网 IP，OBS 地址使用相同 IP。这种用法只适合可信局域网，不要把端口开放到公网。

## 调整点歌规则

打开所用页面的配置：

| 页面 | 文件 |
|---|---|
| Mecha | `bilimani_web/iidx/mecha/config.json` |
| Card | `bilimani_web/iidx/card/config.json` |

`requests.prefix` 是点歌命令，默认“点歌”；`requests.cooldownSeconds` 是同一观众两次点歌的间隔秒数，默认 `0` 表示不限制。保存后，在 OBS 中刷新该浏览器来源。

点歌队列长度和等待开曲的时限在 `bilimani_iidx.json` 中修改，保存后重启游戏。全部字段见[配置说明](behavior.md#配置)。

## 左下角歌曲与玩家信息

Mecha 页面在歌曲信息和 DJ NAME、SP/DP 段位、DJ POINT、本周游玩次数及按键数之间滚动切换。默认每 10 秒换一次；在该页面的 `config.json` 中修改 `display.infoRotationSeconds`，保存并刷新 OBS 浏览器来源即可。可填 1–3600 的整数秒数。

没有登录玩家时只显示歌曲；没有选择歌曲时直接显示玩家。统计采用游戏的“本周”口径，按键数不含转盘；暂无数据时显示 `—`。玩家资料采用数值在上、说明在下的两行网格。

`display.vfdEffects` 默认为 `true`，启用滚动切换、候选屏的机械臂收放，以及歌曲/玩家资料处轻微的随机抖动和短促的局部高频闪动；BPM 保持稳定。动效由页面配置控制，不随 Windows 的动画设置关闭；需要静态展示时改为 `false`，保存并刷新浏览器来源。信息仍按设定间隔切换，候选屏直接显示或隐藏。

Mecha 有多个候选歌曲时，会从画面外伸出机械臂并降下荧光屏，弹幕和队列区域保持原有布局。1P 和 DP 从右侧伸出，2P 从左侧伸出；选完或超时后，先收起屏幕，再逐节收回机械臂。候选仍通过弹幕编号选择，翻页和待选观众轮换直接在屏幕内更新。

## 添加歌曲别名

打开 DLL 旁的 `bilimani_iidx_aliases.csv`，保留第一行 `alias,target`，在下面每行填写一个别名和对应的完整曲名，用英文逗号分隔。例如：

```csv
alias,target
红武士,SAMURAI-Scramble
```

保存为 UTF-8 后，在游戏内菜单选择“重新加载别名 CSV”。如果填写有误，菜单会显示出错的行，之前已加载的别名继续有效。这里的曲名必须存在于当前游戏中。

## 点歌操作

- 发送 `点歌 曲名 SPA` 可以指定谱面。SP 和 DP 支持 B / N / H / A / L 难度。
- 候选歌曲每页显示 5 首，发送 `n` 看下一页，`p` 看上一页，再回复歌曲编号。默认需要在 60 秒内确认。
- 游戏内菜单可以删除队列中的歌曲、优先选某一首、跳过当前点歌以及重新加载别名。菜单打开期间暂停自动选曲。
- 刷新网页保留点歌队列；退出游戏清空队列。

## 常见问题

**网页打不开或显示找不到页面**

先确认游戏已经启动，启动参数中已加载 `bilimani_iidx.dll`，并且 `bilimani_web` 文件夹放在 DLL 旁边。核对 OBS 地址与 README 中一致；修改过监听地址时，OBS 也要同步修改。

**提示读取配置失败**

检查页面目录里的 `config.json` 是否存在。如果缺失，从发布包中补回；如果刚编辑过，检查是否漏了逗号或双引号。

**游戏内菜单打不开**

确认使用单人 SP，在普通选曲界面双击另一侧 Start，并使用 [spice2x 26-09-12 或更新版本](https://github.com/spice2x/spice2x.github.io/releases/tag/26-09-12)。

**需要进一步排查**

查看网页上的错误提示，以及 DLL 旁的 `bilimani_iidx.log`。向开发者反馈时，提供游戏版本、spice2x 版本、错误提示和复现步骤。
