# 0.3.0 更新说明

## bilimani 新名称与独立配置程序

- 项目正式更名为 **bilimani**，DLL 为 `bilimani.dll`，独立配置程序为 `bilimani-config.exe`，网页目录为 `bilimani_web`。
- 无需启动游戏即可打开独立配置程序，管理直播间、点歌规则、歌曲别名及 OBS 设置；与游戏内控制台共用配置。
- 发布包仅包含 DLL、独立配置程序、README 和网页样式目录。`bilimani_web` 下分别提供 `card` 与 `mecha`，不再放置根目录页面副本或许可证文件。

## MECHA 直播框架

- 新增可独立选择的 1920 × 1080 机甲直播框架，保留原有卡片样式。
- 中央透明开口严格为 **16:9（1504 × 846）**，底部横梁增高，边框和灯光不会遮挡游戏画面。
- 底部跟随游戏实际选曲／演奏，显示曲名、作者、曲风、谱面难度、BPM、音符数及六项雷达。
- 右侧显示点歌队列、弹幕与事件；候选列表支持分页和多人轮换，空队列时弹幕区域自动扩展。

## OBS 监听地址

- 「OBS 显示」新增可配置的监听地址，支持 IPv4 和 IPv6，默认仍为 `127.0.0.1`。
- 修改地址或端口后可直接应用；绑定失败时保留原来的监听服务。
- 需要局域网访问时可填写本机局域网 IP 或 `0.0.0.0`，其他设备使用主播电脑的实际 IP 访问。

## 从 0.2.0 升级

1. 退出游戏和配置程序，备份现有配置。
2. 下载并解压 **`bilimani-0.3.0.zip`**，安装 `bilimani.dll`、`bilimani-config.exe` 和 `bilimani_web`。
3. 从旧名称升级时，将 `chart-requester.db` 改名为 `bilimani.db`；仅有旧 TOML 时，将 `chart-requester.toml` 改名为 `bilimani.toml`，首次启动自动迁移。旧 JSON 备份仍可导入。
4. 启动参数改为 **`-k bilimani.dll`**，停用旧 DLL，避免重复加载。已使用 bilimani 名称的用户可直接保留现有数据库。
5. 网页静态目录选择 **`bilimani_web/card`** 或 **`bilimani_web/mecha`**，然后刷新 OBS 浏览器来源；默认 URL 仍为 `http://127.0.0.1:32133/queue`。
6. 使用 Mecha 时，浏览器来源设为 **1920 × 1080**、位置 **(0, 0)**；游戏采集放在其下方，位置 **(40, 48)**、大小 **1504 × 846**，四边裁剪全部设为 **0**，并移除旧裁剪滤镜。卡片样式仍建议 **480 × 800**。

支持的游戏版本仍为 IIDX 33 `LDJ:J:D:A:2026081900`；本次未新增其他游戏构建适配。
