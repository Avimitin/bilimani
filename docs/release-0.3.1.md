# 0.3.1 更新说明

## 原生谱面密度与 VFD 显示

- 从 IIDX 原生谱面分析器读取每秒音符密度和转盘密度，跟随选曲、难度及演奏场景更新；支持 SP、DP 和双人显示。
- Mecha 底栏新增老式 VFD 风格的分段密度表，使用青绿色与暗橙色。按每 5 秒显示平均密度，超过 3 分钟的歌曲使用 10 秒窗口；峰值保留原生每秒统计，未取得数据时显示「暂无密度数据」。
- 难度使用对应颜色的蜂巢荧光底板、深色粗体和锐角平行四边形。BPM 位于难度上方，难度牌底边与密度图对齐。
- 歌曲信息加入明暗不均的细荧光边框，长曲名最多显示两行。

## 机甲框架与弹幕布局

- 顶部边框减薄，底部信息区域增高；中央采集区域仍为 **1504 × 846（16:9）**，位置调整为 **(40, 24)**。
- 放大左下唱盘，以错层装甲连接机身，唱盘装饰局部覆盖游戏画面；左上灯条改为直线，唱盘指示灯移入右下电源模块。
- 右上提示区改为向下突出的梯形装甲，内容居中，直播间名称前使用 bilibili SVG 图标。
- 放大提示文字、弹幕正文与昵称，缩减弹幕区域高度；调整右下雷达位置，避免超出玻璃范围。

## 从 0.3.0 升级

1. 退出游戏和配置程序，备份现有配置。
2. 下载并解压 **`bilimani-0.3.1.zip`**，更新 `bilimani.dll`、`bilimani-config.exe` 和 `bilimani_web`，保留现有 `bilimani.db`。
3. 使用 Mecha 时，OBS 浏览器来源保持 **1920 × 1080**；游戏采集位置改为 **X=40、Y=24**，大小保持 **1504 × 846**，四边裁剪为 **0**。
4. 刷新 OBS 浏览器来源。密度功能需要同时更新 DLL 和 Mecha 静态文件。

支持的游戏版本仍为 IIDX 33 `LDJ:J:D:A:2026081900`；本次未新增其他游戏构建适配。
