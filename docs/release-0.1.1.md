# 0.1.1 更新说明

## 双击另一侧 Start 跳过点歌

单人 SP 的普通选曲界面中，双击另一侧 Start，即可跳过当前点歌并定位到队列中的下一首：

- 1P 游玩：双击 **2P Start**。
- 2P 游玩：双击 **1P Start**。
- 两次按下默认间隔不超过 **400 毫秒**，中间需要松开；长按不会触发。
- 没有下一首时清空当前点歌，游戏仍停留在原歌曲。
- 只读取按键，不拦截游戏原有操作；DP、双人游玩、游玩途中和菜单弹窗内不生效。

此功能默认开启，需要支持 Spice SDK 的 Spice2x，已完成实机验证。缺少 SDK 按键接口时，其他点歌功能仍可使用。日志中的 `[input]` 会记录当前可用侧、接口状态及双击处理结果。

可在配置中添加以下分组；已有时直接修改，保存后重启游戏：

```toml
[controls]
skip_enabled = true  # 改为 false 关闭
double_tap_ms = 400 # 双击间隔，支持 100–2000 毫秒
```

## OBS 网页面板

- DLL 内置本地网页服务，无需安装额外软件。
- 在 OBS 添加「浏览器」来源，地址填写 `http://127.0.0.1:32133/queue`，建议尺寸 **480 × 800**。
- 紧凑队列面板顶部显示点歌格式；候选选择、通知及断线提示在底部按需弹出。
- 普通通知 6 秒后收起；多人等待选择时，每 6 秒轮换一位观众的候选。
- 页面始终显示实时状态，没有示例模式。原有两个 OBS 文本文件仍可使用。

## 升级方法

退出游戏，解压 `chart-requester-0.1.1.zip` 并替换 DLL，保留自己的 `chart-requester.toml`，然后重启游戏。旧配置自动使用新增设置的默认值。

如果之前试用版中添加过独立 `/interaction` 浏览器来源，请删除或隐藏它，只保留 `/queue`。

支持的游戏 DLL 版本未改变，仍以 README 中列出的 IIDX 33 构建为准。
